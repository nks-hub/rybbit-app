# Tester recruitment — closed testing (Alpha)

Opt-in link: <https://play.google.com/apps/testing/com.nkshub.rybbit_unofficial>
Feedback: <https://github.com/nks-hub/rybbit-app/issues>

Play requires 12 testers opted in for 14 consecutive days before production
access. Google judges *engagement*, not just the count, so a tester who installs
and never opens the app is worse than no tester at all.

## Reddit

Reddit serves a reCAPTCHA wall to automated browsers and its User Agreement
forbids creating accounts by automated means, so signup has to be done by hand.
A brand-new account posting app links also tends to get filtered on sight —
better to use an account with some history.

Subreddits worth trying, most relevant first:

- **r/TestersCommunity** — built specifically for the 12/14 requirement
- **r/AndroidClosedTesting**
- **r/alphaandbetausers**
- **r/androiddev** — check the rules first; self-promo is usually restricted to
  a pinned thread

Read each subreddit's rules before posting; several allow tester requests only
in a weekly megathread.

Free, no ads, no third-party trackers, AGPL-3.0.

>
