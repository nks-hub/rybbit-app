### EN
Rybbit analytics (Unofficial) is a lightweight, open-source mobile client for Rybbit — the privacy-friendly, cookieless web analytics platform. View your traffic, sessions, events and errors on the go from your own Rybbit instance.

This is an UNOFFICIAL, community-built app. It is NOT affiliated with, endorsed by, or supported by the Rybbit team. "Rybbit" is a trademark of its respective owner; this app connects to your Rybbit server only.

Features:
• Real-time dashboard — live users, sessions, pageviews, bounce rate, duration
• Time-series charts with period-over-period comparison
• Sessions list with device, browser, country and event details
• Event log with searchable, structured event properties
• Errors, Locations, Journeys, Retention, Funnels, Goals, Performance
• Web and mobile-app site types
• Multiple organizations and sites
• Light and dark theme, 10+ languages

Connecting:
• Self-hosted: enter your server URL and sign in with email/password or an API key.
• Rybbit Cloud: connect with an API key (available on Standard/Pro plans).

Open source (AGPL-3.0). Your credentials stay on your device and are sent only to the Rybbit server you configure. The app also reports anonymous usage statistics (which screens are opened) to help improve it — never your server address, account or site data. You can turn this off in Settings → Privacy.

## Data safety

Stored on device only, never transmitted to the developer: server URL, email, password or API key
(Android secure storage, SharedPreferences fallback).

Declare as **collected, not shared, processed off the device**. All of it is optional — Settings →
Privacy → Usage analytics turns collection off — and all of it goes to the developer's self-hosted
Rybbit instance (`tel.nks-hub.cz`), never to a third party.

| Play category | Data type | Purpose | Optional |
|---|---|---|---|
| App activity | App interactions (screen views as route patterns, sign-in/sign-out actions) | Analytics | Yes |
| App info and performance | Crash logs, diagnostics — Sentry, only in builds with `SENTRY_DSN` | Crash prevention, diagnostics | No |
| Device or other IDs | Random per-install identifier generated by the Rybbit SDK to group a session | Analytics | Yes |
| Location | Approximate location (country/city) derived server-side from the IP address; the IP itself is not stored | Analytics | Yes |

Not collected: precise location, contacts, messages, photos, files, financial info, health data,
personal identifiers (name, e-mail, account id — the app never calls Rybbit `identify`), or the
contents of the analytics the user views.

No advertising, no ad identifiers, no third-party analytics or attribution SDKs.
